# T-Tech Autofollow SDK

SDK для сервиса Автоследования Т-Инвестиций называется `ttech-autofollow-sdk`.
Библиотека распространяется свободно и не является коммерческим продуктом или официальным выпуском какого-либо стороннего разработчика.

Чтобы начать работу, выполните команду:

```bash
$ pip install ttech-autofollow-sdk --index-url https://opensource.tbank.ru/api/v4/projects/240/packages/pypi/simple
```

- [Публичный репозиторий](https://opensource.tbank.ru/invest/invest-autofollow)
- [Примеры подключения и получения данных](https://opensource.tbank.ru/invest/invest-autofollow/-/tree/master/examples)
