# Проблемы подключения к T-Invest API

Со стороны брокера нет `черных списков` адресов, которым запрещено подключаться к API. Доступ открыт для всех.
Тем не менее при взаимодействии с API могут возникать проблемы с подключением. Причины проблем могут быть различными, некоторые из них:

- Нестабильное интернет-соединение.
- Отсутствие установленных сертификатов НУЦ Минцифры РФ.
- Ограничения, применяемые провайдерами интернет-сервисов для регулирования трафика.


### Проблемы с интернет-соединением

Причиной ошибок взаимодействия с API может быть нестабильное интернет-соединение. Можно попробовать провести диагностику:

- Выполните в команду `telnet  invest-public-api.tbank.ru 443` в терминале. Если соединение установлено, то базово доступ к сервисам API открыт.
- По возможности, попробуйте подключиться к API из другой сети, например, раздав мобильный интернет со смартфона или из общедоступной сети(кафе, кинотеатр и т.п.) и проверить работу.
- Можно попробовать подключиться к API через VPN.


### Сертификаты НУЦ Минцифры РФ

При работе с API могут возникнуть ошибки, связанные с сертификатом:

- `the SSL connection could not be established`;
- `failed to connect to all addresses`;
- `handshake failed`;
- `certificate verify failed`;

Взаимодействие с API предполагает наличие сертификатов НУЦ Минцифры РФ. Установить
сертификаты можно на [сайте Госуслуг](https://www.gosuslugi.ru/crt).

Импорт сертификатов в приложение описан на [странице](/invest/intro/intro/cases).


### Сетевые ограничения

Ограничения, применяемые провайдерами разных уровней, могут вызывать проблемы при подключении к интернет-ресурсам, а также ограничивать трафик:

- Публичные VPN сервисы часто блокируются по протоколам. Если вы используете VPN, то проверьте, что он не ограничивает трафик.
- Провайдер может ограничивать трафик. Попробуйте временно переключить сеть на другой провайдера.



## Сообщить об ошибке

Если вы столкнулись с проблемой подключения к API, провели первичную диагностику и она не помогает,
сообщите нам о проблеме на [почту](mailto:invest-public-api@tbank.ru), приложив детали:

- описание проблемы;
- ваш IP-адрес;
- используете ли VPN;
- язык программирования и SDK(если применимо);
